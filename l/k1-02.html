짧은 줄이 두 개면 어떤 소리가 날까?

"여우"와 "우유"를 소리 내 읽어 봐요. 지난번 모음에 짧은 줄을 하나 더 그으면 새 소리가 생겨요!

짧은 줄을 하나 더!

ㅏ에 짧은 줄을 더 그으면 ㅑ예요.

ㅓ에 하나 더 그으면 ㅕ예요.

ㅏ → ㅑ (아 → 야) · ㅓ → ㅕ (어 → 여)

누운 모음도 두 줄

ㅗ에 짧은 줄을 더하면 ㅛ예요.

ㅜ에 하나 더하면 ㅠ예요.

ㅗ → ㅛ (오 → 요) · ㅜ → ㅠ (우 → 유)

'이'를 살짝 붙인 소리

"이"와 "아"를 빨리 이어 말해 봐요.

"야" 소리가 나지요?

ㅑ ㅕ ㅛ ㅠ는 이렇게 생긴 소리예요.

이+아 → 야 · 이+어 → 여 · 이+오 → 요 · 이+우 → 유

낱말을 읽어요

배운 모음으로 낱말을 읽어요.

모음 열 개를 차례로 외워 봐요.

여우 · 우유 · 요요 · 아야!
